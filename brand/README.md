# Skynot Labs brand

How Skynot Labs names itself and how it talks. It fits one screen on purpose.

## The name

Skynot means "not Skynet": the agents here ask before they act. The "not" is the point. The mark is drawn as a knot, but the name is not a pun on it.

## Casing

- `skynot`, lowercase, only in the wordmark and in identifiers: `skynot-labs`, `skynot-shop`.
- "Skynot" and "Skynot Labs" in prose.

## The lines

| | |
| --- | --- |
| The lab | Adrian Castillo's lab for learning AI by building. |
| The lab, short | Not Skynet. |
| Skynot | A dev shop of AI agents. |
| Skynot, short | Your judgment. A team of agents. |

Use them as written. The pages, this organization's profile and the GitHub App listing read them from [`console/src/github/site.json`](https://github.com/skynot-labs/skynot/blob/main/console/src/github/site.json) in the skynot repository.

## Voice

- First person singular. The lab is one person, so "we" is not true.
- Say what a thing does and what state it is in. Write "in development" while it is.
- Say what is not known yet.
- Cut any sentence that would still read fine with another product's name in it.
- Call the reader "you". "The director" is the service's own word for them and stays inside the product.

## The mark and the colors

The mark is one continuous stroke. Mint is the lab and Skynot; lavender is the GitHub App.

The mark's geometry, the color tokens and the generated logos, avatars and social card live in the skynot repository, under [`console/src/design/`](https://github.com/skynot-labs/skynot/tree/main/console/src/design) and [`console/public/`](https://github.com/skynot-labs/skynot/tree/main/console/public). They move here when a second project needs them.
